## Introduction

The Departmental Website is designed specifically for the Electrical Engineering Department to enhance communication, collaboration, and information dissemination within the department. It provides features for both faculty and students to contribute content, including research articles and academic resources.

## Features

- **Faculty Profiles**: The website includes profiles of faculty members, providing information about their areas of expertise, research interests, and contact details.
  
- **Student Profiles**: Students can create profiles to showcase their achievements, research projects, and other relevant information.

- **Research Articles**: Faculty and students can publish research articles and papers on the website, allowing for easy dissemination of knowledge within the department.

- **Academic Resources**: The website offers access to academic resources such as lecture notes, study materials, and reference books.

- **Authentication System**: Users can log in securely using their credentials, ensuring that only authorized individuals can contribute content to the website.

## Usage

### Faculty

1. **Login**: Faculty members can log in using their credentials to access their profiles and contribute content.
   
2. **Profile Management**: Faculty can update their profiles with the latest information about their research projects, publications, and contact details.
   
3. **Publishing Articles**: Faculty members can publish research articles, conference papers, and other academic content on the website.

### Students

1. **Login**: Students can log in using their credentials to access their profiles and contribute content.
   
2. **Profile Creation**: Students can create profiles to showcase their academic achievements, research projects, and interests.
   
3. **Writing Articles**: Students can contribute articles, blog posts, and other content related to their research projects or academic interests.

## Installation

To set up the Departmental Website locally for development or testing purposes, follow these steps:

1. **Clone the Repository**: Clone the repository to your local machine using Git:
   ```
   git clone https://github.com/ishwerdutt/electrical.git
   ```

2. **Install Dependencies**: Install the required dependencies using the appropriate package manager for your environment.

3. **Database Setup**: Configure the database settings according to your environment. Make sure to run database migrations to set up the database schema.

4. **Run the Server**: Start the development server and navigate to the website URL in your web browser to access the website.

## Technologies Used

The Departmental Website is built using the following technologies:

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django Framework
- Database: SQLite (for development), PostgreSQL (for production)
- Authentication: Django Authentication System
- Version Control: Git, GitHub
